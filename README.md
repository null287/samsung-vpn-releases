# Samsung VPN — APK & Core Releases

This is the **public distribution-only repository** for Samsung VPN, an unofficial Android client customized from [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid) (GPL-3.0). It is **not affiliated with Samsung**.

Each published version provides application APKs, a corresponding source-code archive, and release metadata. Independent core update manifests and signed core components are included where applicable. Source code and bundled upstream notices remain available with each release.

**Downloads:** [GitHub Releases](https://github.com/null287/samsung-vpn-releases/releases). Choose the APK for your device's CPU architecture; Galaxy S23 Ultra and Tab S9+ use `arm64-v8a`. Verify the package identity, signature and release SHA-256 before replacing an installed version.

**Important:** Network profiles, subscriptions, signing keys and personal configuration files are never part of the published artifacts. Real-device testing and operational limitations are described in each release's notes.

The development repository is private. Public APK distribution does not imply endorsement or certification by Samsung or the upstream project.
